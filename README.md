# DotfilesArchive

个人 Umbriel + Noctalia 配置，偏向 TUI，仅供参考。

## 布局

真机路径映射在 `data/` 下。

## 使用

需要 Python 3、PyYAML，运行 `./sync.py`。
dotfile_refer.yaml中包含需要备份的配置文件目录和需要过滤的文件类型.
*注意sync.py, dotfile_refer.yaml为ai生成
*注意配置仅供参考
